# Leyes de Senos y Cosenos · Guía interactiva de autoestudio

Matemáticas V · Preparatoria Xochicalco · Parcial 3

- `index.html`: guía para estudiantes (registro, repaso, clasificador, 7 retos con variantes por alumno, calculadora en grados y comprobante con código de verificación).
- `verificar.html`: página docente para validar el código del comprobante y consultar la variante (datos y respuestas) de cada alumno.

Funciona sin servidor; se publica con GitHub Pages desde la rama `main`.
