# Instrucciones para este repositorio

- Todo material dirigido a estudiantes (páginas, comprobantes, documentos imprimibles) debe incluir el crédito de autoría: **Elaborado por Dr. T. Huerta**.
  - En las guías interactivas aparece en la barra inferior fija y al pie del comprobante imprimible.
  - Al crear una página o guía nueva, añadir el mismo crédito.
- Las páginas se publican con GitHub Pages desde la rama `main`.
